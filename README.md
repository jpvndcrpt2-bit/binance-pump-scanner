# binance-pump-scanner — اسکنر کوین‌های پامپ‌شده فیوچرز بایننس

همهٔ قراردادهای دائمی USDT بایننس فیوچرز را می‌خواند، آن‌هایی که **کندل روزانه‌شان (روز UTC) حداقل ۵۰٪ مثبت** است را جدا می‌کند و برای هرکدام «سرنخ دلیل رشد» جمع می‌کند. خروجی یک گزارش HTML است. بدون نصب پکیج، بدون API key، و هیچ سفارشی ارسال نمی‌کند.

## اجرا (ویندوز)

- دابل‌کلیک روی `scan.bat`: یک اسکن و باز شدن گزارش
- دابل‌کلیک روی `loop.bat`: هر ۱۵ دقیقه اسکن تکراری؛ فقط کوین‌های تازه بررسی و گزارش به‌روز می‌شود

یا در ترمینال:

```
py pump.py                       # امروز (کندلِ در حال تشکیل)
py pump.py --date 2026-10-27     # یک روز مشخص (UTC)
py pump.py --min 30              # آستانهٔ دیگر
py pump.py --metric high         # سقف نسبت به باز (اسپایک‌هایی که برگشته‌اند هم بیاید)
py pump.py --no-news             # سریع؛ بدون CoinGecko و خبر
py pump.py --open                # باز کردن گزارش در مرورگر
```

خروجی: `output\<تاریخ>\report.html` و `results.json`.
کندل روزانه بایننس ساعت **۰۳:۰۰ بغداد** شروع می‌شود.

## برای هر کوین چه چیزی در گزارش هست

- درصد تغییر (باز→بسته و باز→سقف)، حجم دلاری، فاندینگ و تغییر Open Interest
- **اعلان‌های بایننس** که اسم کوین در آن‌هاست (لیست جدید و اخبار)
- برچسب «لیست جدید در فیوچرز» اگر کمتر از ۱۴ روز از لیست شدنش گذشته
- پروفایل **CoinGecko**: نام، رتبه، مارکت‌کپ، دسته‌ها، توضیح کوتاه
- تیترهای اخیر **Google News** دربارهٔ کوین
- لینک آمادهٔ جست‌وجو در **X، Binance Square، Reddit، CoinMarketCap، CoinGecko**

## تلگرام و CryptoPanic

در `config.json` (کپی از `config.example.json`):

```json
{
  "telegram_channels": ["binance_announcements", "اسم_کانال_عمومی_دیگر"],
  "cryptopanic_token": "کلید_تو"
}
```

- **تلگرام** بدون key و رایگان است: پیش‌نمایش عمومی `t.me/s/<کانال>` خوانده می‌شود. فقط کانال‌های عمومی که پیش‌نمایش وب دارند کار می‌کنند. فقط پستی نشان داده می‌شود که اسم کوین را دقیقاً داشته باشد و در `telegram_days` روز اخیر باشد.
- فقط `binance_announcements` پیش‌فرض است (کانال رسمی اعلان‌ها؛ وجودش را از این محیط تأیید نکردم). **کانال‌های معتبر دیگر را خودت اضافه کن.** من اسم کانال «معتبر پامپ» حدس نمی‌زنم؛ بسیاری از کانال‌های سیگنال/پامپ خودشان عامل دستکاری‌اند، پس پست آن‌ها را سرنخ بدان، نه تأیید.
- **CryptoPanic** فقط وقتی `cryptopanic_token` پر باشد فعال می‌شود. یک منبع می‌گوید پلن رایگان API حذف شده و API به پلن پولی نیاز دارد؛ این را مستقیم از خود CryptoPanic تأیید نکردم. قبل از خرید خودت قیمت را در cryptopanic.com/developers/api ببین. آدرس API در `cryptopanic_url` قابل تغییر است. اگر ساختار جواب فرق کند، بخش خبرش خالی می‌ماند و بقیه کار می‌کند.
- Key را فقط روی کامپیوتر خودت در `config.json` نگه دار (در `.gitignore` هست) و در گیت‌هاب یا نسخهٔ وب نگذار.

## محدودیت‌های صادقانه

- **شبکه‌های اجتماعی خوانده نمی‌شوند.** X و تلگرام و Square API رایگان ندارند. به‌جایش لینک جست‌وجو در هر کارت هست.
- CoinGecko کوین را با «نماد» پیدا می‌کند و چند ارز هم‌نماد زیاد است. اگر ابهام باشد برچسب هشدار و اسم نمادهای هم‌نام را می‌بینی؛ تطبیق را خودت چک کن.
- خبرها سرنخ‌اند، نه اثبات علت. اگر هیچ خبری پیدا نشود، برچسب «خبر/اعلانی پیدا نشد» می‌خورد و معمولاً یعنی نقدینگی کم یا دستکاری. استنتاج بیشتر را خودت یا با Claude انجام بده (محتوای `results.json` را بده).
- CoinGecko رایگان محدودیت نرخ دارد؛ هر کوین چند ثانیه طول می‌کشد.
- اگر بایننس از شبکهٔ شما بلاک باشد (خطای 451/403) از VPN استفاده کن.
- شناسه‌های اعلان‌های بایننس (catalogId) غیررسمی‌اند و ممکن است تغییر کنند؛ در آن صورت فقط بخش اعلان خالی می‌ماند.

## تنظیمات (اختیاری)

`config.example.json` را به `config.json` کپی کن: `min_change_pct`، `metric`، `min_quote_volume_usd` (پیش‌فرض ۵۰۰ هزار دلار، برای حذف قراردادهای بی‌حجم)، `news_days`، `max_news`.
اگر اسم یک تنظیم اشتباه باشد خطا می‌دهد.

**اعلان تلگرام (اختیاری):** اگر `telegram.token` و `telegram.chat_id` را پر کنی، در حالت `--loop` برای هر کوین تازه یک پیام کوتاه می‌آید.

## تست

```
py -m unittest discover -s tests
```

۲۰ تست آفلاین با داده ساختگی. اتصال زنده به بایننس/CoinGecko/Google News در محیط ساخت تست نشد؛ اولین اجرا را خودت ببین و اگر خطا بود پیامش را بفرست.

توصیهٔ مالی نیست. کوین‌هایی که ۵۰٪ پامپ شده‌اند معمولاً پرنوسان و پرریسک‌اند.

## نسخهٔ وب (پوشهٔ `web`)

یک سایت استاتیک (`index.html` + `app.js`) با همان منطق، برای انتشار روی هر هاست رایگان (Vercel، Netlify، Cloudflare Pages، GitHub Pages): فقط پوشهٔ `web` را آپلود کن.

- همهٔ درخواست‌ها را **مرورگر بازدیدکننده** به بایننس و CoinGecko می‌زند. سرور وسط نیست، چون بایننس IPهای آمریکا را بلاک می‌کند و هاست‌های خارجی روی سرور خطا می‌دادند.
- اگر بازدیدکننده در کشوری باشد که بایننس بلاک است، پیام خطای واضح می‌بیند (VPN).
- خبرها در نسخهٔ وب لینک جست‌وجوی Google News/X/Square/Reddit هستند (Google News اجازهٔ خواندن مستقیم از مرورگر نمی‌دهد)؛ پروفایل CoinGecko، فاندینگ و OI خودکار می‌آید.
- برای اسکن امروز، اول یک فیلتر دقیق روی تیکر ۲۴ساعته اعمال می‌شود و فقط چند کوین کاندید کندل می‌گیرند (سریع). برای روز گذشته همهٔ قراردادها بررسی می‌شوند (کندتر).
- تست منطق: `node web/test.js`
- اتصال زنده به بایننس/CoinGecko با CORS در محیط ساخت تست نشد؛ در مرورگر با پاسخ‌های شبیه‌سازی‌شده تست شد. بعد از انتشار یک بار باز کن و ببین.
